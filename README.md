Personal portfolio website for **Nosib Biswas**, showcasing projects, technical skills, and contact information.

## Features

- Responsive portfolio layout
- About, skills, portfolio, and contact sections
- Project previews with links to live demos
- Mobile navigation and theme support

## Built With

- HTML5
- CSS3 and Sass
- JavaScript
- Boxicons and Font Awesome

## Getting Started

This is a static website and does not require a build step.

1. Clone the repository:

   ```bash
   git clone https://github.com/nosibbiswas22/nosibbiswas.git
   ```

2. Open `index.html` in a browser, or serve the project with any local static web server.
