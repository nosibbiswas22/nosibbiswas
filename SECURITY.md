# Security Policy

## Supported Versions

This project is a static portfolio website. Security fixes are currently provided for the latest released version:

| Version | Supported |
| --- | --- |
| 1.0.x | Yes |
| < 1.0.0 | No |

## Reporting a Vulnerability

Please do not disclose security vulnerabilities in a public issue.

Report a suspected vulnerability privately by emailing [nosib.biswas22@gmail.com](mailto:nosib.biswas22@gmail.com) with:

- A clear description of the issue
- The affected page, file, or component
- Steps to reproduce the issue
- Any relevant screenshots, logs, or proof-of-concept details

You can expect an acknowledgment within 7 days. Once the issue is confirmed, reasonable steps will be taken to investigate, fix, and communicate the resolution.
